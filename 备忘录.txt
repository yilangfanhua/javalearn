AccountMapper的作用是查询和保存账号，可它只声明了两个方法，具体访问数据库是在哪，查询和保存账号

SecurityConfig
    配置哪些接口公开、哪些接口需要认证

AuthController
    接收注册和登录请求

AuthService
    编排注册和登录业务

AccountMapper
    查询和保存账号

AccountUserDetailsService
    把数据库账号转换成 UserDetails

JwtService
    创建、解析、验证 JWT

JwtAuthenticationFilter
    每次请求读取 JWT，并建立当前用户身份


登录：
Controller
 → AuthService
 → AuthenticationManager
 → UserDetailsService
 → PasswordEncoder
 → JwtService
 → 返回 Token

访问：
请求
 → JwtAuthenticationFilter
 → JwtService 验证 Token
 → UserDetailsService 查询用户
 → SecurityContextHolder 保存身份
 → SecurityConfig 判断权限
 → Controller
